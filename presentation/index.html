Why it matters

A swarm is strong because one agent's finding becomes everyone's finding.

Defences today look at one agent at a time. Nobody attacks the sharing.

The idea

The latest security fixes are not enough

STATIC DEFENCE · TODAY

Patch, block, wait for the next attack

Every fix is a fixed target. A swarm points more agents at it, and whatever one agent learns, all of them know. Blocking just sends them to try again somewhere else.

DYNAMIC DEFENCE · SWARMSHIELD

A moving target that spends their resources

Every attacker sees a different, consistent world. Each attempt costs them tokens and time; each fake page costs us a fraction of a cent. The more agents they add, the more they contradict each other.

Don't just harden the target. Make attacking it expensive.

Defender cost is simulated in today's demo.

The idea

Fight a swarm with a swarm

RED SWARM · ATTACKERS

Four agents, one shared board

  • recon-1 finds an API key in the docs
  • creds-2 uses the key, finds a backup
  • exploit-3 reads the backup, gets the admin password
  • coord-4 logs in and takes the flag

Wins when the flag is captured.

BLUE SWARM · SWARMSHIELD

One Sentinel, one Warden per attacker

  • Sentinel spots the agents working together
  • Warden ×N: one per attacker, each serving its own consistent fake world
  • Wardens coordinate on a blue board so no two realities agree

Wins when the swarm splits, the flag is safe and real users never notice.

How it works

Detect, deceive, disrupt

01 · SENTINEL

Detect

Every agent gets its own copy of each secret. When creds-2 sends the key we gave recon-1, they're a team. Backups: honey links, the hidden /admin, 404s, request rate.

02 · WARDENS

Deceive

Each flagged attacker gets its own Warden and its own reality: its own key, password and admin path, all working. Flagged traffic never reaches the real app.

03 · THE SWARM ITSELF

Disrupt

The realities contradict each other. Every tip a teammate shares fails for whoever tries it. Trust drops, agents go lone, the swarm splits.

Why it holds up

It survives the obvious countermeasures

Signed messages

Signing proves who said something, not that it's true. A signed contradiction is still a contradiction, and teammates trust it more.

Agents trained to distrust each other

That cuts their own coordination. They either keep sharing and contradict each other, or stop sharing and become slow lone agents.

Comparing notes

Possible, and that's the cost we impose: every cross-check burns tokens and time, and none of the realities is the real one.

We never touch the attackers' channel. The contradictions come only from what our own API returns.
